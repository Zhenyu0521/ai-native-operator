# Personal Site Demo Design

## Goal

Create a first-pass personal website demo for an AI Native Operator: a builder exploring how AI changes knowledge work, with a homepage that is simple, spacious, practical, and credible.

## Positioning

The site presents the owner as a builder and knowledge worker practicing AI-native work, not as a single-tool expert. The core belief is that AI does not merely replace people; it reorganizes how knowledge work is done so one person can hold capabilities that previously required a team.

## Homepage Structure

The homepage is a single static page with these sections:

1. Header with simple navigation anchors.
2. Hero with "AI Native Operator" and "Building the Future of AI-Native Work".
3. Philosophy section explaining the belief in reorganized knowledge work.
4. Explore / Build / Share architecture with the user's categories.
5. Evidence section based on public projects, workflows, failures, products, and experiments.
6. Product architecture section for career coaching, data analysis mentoring, and other courses.
7. Closing call to follow the work in public.

## Visual Direction

Use a restrained Pika/Anthropic-inspired style: editorial typography, generous whitespace, thin borders, a neutral palette, and one warm accent. Avoid heavy tech gradients, landing-page clutter, nested cards, or decorative blobs.

## Constraints

- Static files only.
- No external dependencies.
- Must work by opening `index.html` directly.
- Keep copy editable in HTML.
- Use responsive CSS for desktop and mobile.
