Codex Workflow Skill

Sync Feishu Learning to Site

Turn a selected Feishu document section into a tested Learning article, then publish only after confirmation.

这个 Skill 把飞书文档读取、文章定位、页面生成、本地测试、迭代记录和 GitHub Actions 发布串成一条可重复执行的工作流。

How It Works

四步把飞书章节变成线上 Learning 文章。

01

定位章节

读取飞书文档，并用完全一致的一级标题锁定需要发布的内容。

02

生成页面

确认栏目、slug、标签和摘要，再生成文章页与 Learning 卡片。

03

校验与记录

重复运行同步脚本，执行测试和 JSON 校验，并更新项目迭代记录。

04

确认后发布

只提交目标文件，推送 GitHub，并确认 Deploy site 成功后检查线上页面。

Required Inputs

开始前只需要确认四件事。

  • 飞书文档链接。
  • 与文档中一级标题完全一致的文章标题。
  • AI-Native 工作理念，或 AI-Native 工作方法。
  • 只生成本地预览，或预览后发布到线上。

Installation

从网站仓库安装到 Codex。

在 ai-native-operator 仓库根目录运行：

mkdir -p ~/.codex/skills
cp -R skills/sync-feishu-learning-to-site ~/.codex/skills/

Safety Boundaries

自动化负责执行，发布权仍然留在人手里。

明确授权

没有明确的线上发布请求，就只生成和验证本地预览。

精确提交

发布前检查工作区，只提交目标文章、页面和必要配置。

凭证隔离

不写入飞书认证、GitHub token、部署 Secret 或本机绝对路径。

结果可验证

同时检查测试、GitHub 提交、部署任务和最终线上页面。
